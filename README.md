Open the USB setup page in desktop Chrome or Edge on the computer connected to the phone. No local ADB folder or setup script is required. Enable USB debugging and approve access on the phone. Windows may require the manufacturer's USB driver.

The new family reliability, diagnostic sharing, bookmarks and summary features require the matching backend update and migrations. Preserve the server's environment and application key. Backend source and credentials are not published here.

Signed APKs are attached under Releases. This public repository contains the release index and browser USB setup tools, not the private application source.
